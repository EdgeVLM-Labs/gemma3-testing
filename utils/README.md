# Utility Scripts

| Script | Purpose |
|--------|---------|
| `load_dataset.py` | Download QVED dataset from HuggingFace |
| `filter_ground_truth.py` | Filter ground truth labels to downloaded videos |
| `clean_dataset.py` | Clean and validate dataset |
| `qved_from_fine_labels.py` | Convert fine-grained labels to QVED format |
| `fix_manifest_format.py` | Fix manifest.json formatting |
| `hf_upload.py` | Upload model to HuggingFace Hub |
| `test_inference.py` | Batch inference (legacy model) |
| `test_inference_transformers.py` | Batch inference (transformers) |
| `generate_test_report.py` | Generate evaluation report (requires openpyxl) |
| `plot_training_stats.py` | Plot training curves (requires matplotlib) |
| `motion_classifier.py` | Motion classification utility |
